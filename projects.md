# Projects

## Concept-Aware Foundation Model Pretraining

This project studies whether selecting informative training examples can improve foundation model learning efficiency under fixed compute budgets.

Research directions:

- Data selection for pretraining
- Concept-based retrieval
- Curriculum learning
- Training signal discovery

## CPU-Efficient Data Selection Signals

Early experiments explored lightweight CPU-based signals for identifying useful training examples without requiring expensive per-example model computations.

Research questions:

- Can inexpensive signals identify valuable examples?
- How can data diversity and information content be measured?
- Can pretraining efficiency improve through better sample selection?

## Memory Systems for AI Agents

This project investigates architectures that allow AI agents to maintain and use long-term information.

Research directions:

- Memory retrieval
- Episodic and semantic memory
- Learnable memory policies
- Long-horizon agent evaluation
